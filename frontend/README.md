# 🏥 نظام الشهادات الصحية — الواجهة الأمامية (Frontend)

> واجهة أمامية لنظام إدارة وإصدار الشهادات الصحية التابع لوزارة البلديات والإسكان (بلدي)

---

## 📋 نظرة عامة

تطبيق React SPA لإدارة وعرض وطباعة الشهادات الصحية الموحدة. يتصل بـ Backend API لتخزين البيانات واسترجاعها، ويدعم التقويم الهجري والميلادي، وتوليد أكواد QR، وتصدير PDF.

## 🗺️ المسارات (Routes)

| المسار | المكون | الوصف | الحماية |
|--------|--------|-------|---------|
| `/` | `Login` | صفحة تسجيل الدخول | ❌ عام |
| `/dashboard` | `Dashboard` | لوحة التحكم (عرض/حذف/قفل الشهادات) | ✅ يتطلب Token |
| `/add-certificate` | `AddCertificate` | إضافة شهادة جديدة | ✅ يتطلب Token |
| `/edit-certificate/:id` | `EditCertificate` | تعديل شهادة موجودة | ✅ يتطلب Token |
| `/certificate/:id` | `CertificatePage` | عرض الشهادة للطباعة/تحميل PDF | ✅ يتطلب Token |
| `/view/:id` | `CertificateView` | عرض الشهادة العام (رابط QR) | ❌ عام |
| `/certificates` | `AllCertificates` | جدول كل الشهادات | ✅ يتطلب Token |

## 📄 تفاصيل الصفحات

### 🔐 Login — تسجيل الدخول
- إدخال اسم المستخدم وكلمة المرور
- يرسل `POST /api/login` ← يحصل على JWT Token ← يُخزن في `localStorage`
- القيم الافتراضية: `admin` / `123456`

### 📊 Dashboard — لوحة التحكم
- عرض جميع الشهادات على شكل بطاقات (Cards)
- لكل شهادة: عرض الصورة، الاسم، رقم الهوية، الجنسية
- أزرار: **عرض** 👁️ | **تعديل** ✏️ | **حذف** 🗑️ | **تحميل JSON** 📥 | **قفل/فتح** 🔒🔓
- **نسخ احتياطي** 💾 — تحميل كل الشهادات كملف JSON (يدعم File System Access API)
- **استيراد نسخة** 📂 — رفع ملف JSON لاستعادة الشهادات
- تسجيل الخروج

### ➕ AddCertificate — إضافة شهادة
**الحقول:**
| الحقل | النوع | ملاحظات |
|-------|-------|---------|
| اسم الشخص | نص | مطلوب |
| رقم الرخصة | نص | عند الإدخال + blur يبحث تلقائياً عن بيانات رخصة سابقة |
| اسم/رقم المنشأة | نص | يُملأ تلقائياً من الرخصة |
| الأمانة | قائمة منسدلة | 17 أمانة من `baladyData.js` — يُغير اللوجو تلقائياً |
| البلدية | قائمة منسدلة | تتغير حسب الأمانة + خيار "أخرى" للإدخال اليدوي |
| رقم الهوية | نص | مطلوب |
| الجنس | نص | ذكر / أنثى |
| رقم الشهادة الصحية | نص | يُحسب تلقائياً (auto-increment من API) |
| الجنسية | نص | — |
| المهنة | نص | — |
| تاريخ الإصدار (ميلادي) | تاريخ | افتراضي: اليوم |
| تاريخ الإصدار (هجري) | نص | يُحسب تلقائياً |
| تاريخ الانتهاء (ميلادي) | تاريخ | افتراضي: بعد سنة |
| تاريخ الانتهاء (هجري) | نص | يُحسب تلقائياً |
| نوع البرنامج التثقيفي | نص | — |
| تاريخ انتهاء البرنامج (هجري) | نص | افتراضي: بعد 3 سنوات |
| صورة الشخص | ملف | يُرفع إلى Cloudinary عبر الـ Backend |

**ميزات ذكية:**
- حساب التقويم الهجري تلقائياً باستخدام `Intl.DateTimeFormat` مع `islamic-umalqura`
- بحث تلقائي بالرخصة لملء بيانات المنشأة والأمانة

### ✏️ EditCertificate — تعديل شهادة
- نفس حقول الإضافة + خيار **قفل الشهادة** (منع العرض العام)
- يدعم إدخال الأمانة يدوياً بالإضافة للقائمة
- تعديل مسار اللوجو يدوياً

### 🖨️ CertificatePage — عرض للطباعة
**4 أنواع شهادات:**
| النوع | اللون | 
|-------|-------|
| `annual` — شهادة صحية سنوية | `#42ce23` أخضر فاتح |
| `basic` — شهادة صحية | `#8bcb6c` أخضر باهت |
| `health` — شهادة صحية | `#428181` تيل |
| `unified` — الشهادة الصحية الموحدة | `#428181` تيل (افتراضي) |

**مكونات الشهادة:**
1. **الهيدر**: 3 شعارات (وزارة + بلدي + شعار الأمانة المُختار) + شريط ملون بعنوان النوع
2. **المحتوى**: صورة الشخص + كود QR (يُشير لـ `/view/:id`) + بيانات الشخص
3. **الفوتر**: شريط روابط (الموقع، سوشيال ميديا، خدمة العملاء 199040)
4. **صفحة التعليمات**: تعليمات وإرشادات الشهادة الصحية مع شعارات الوزارة ورؤية 2030

**تصدير PDF:**
- يُنتج PDF من صفحتين (landscape A4):
  - الصفحة 1: الشهادة نفسها
  - الصفحة 2: التعليمات والإرشادات
- يستخدم `html-to-image` + `jsPDF` بدقة `pixelRatio: 3`
- **ملاءمة الاسم تلقائياً**: ألگوريثم 3 مراحل (تضييق المسافة بين الكلمات → تضييق المسافة بين الحروف → تصغير حجم الخط)

### 👁️ CertificateView — العرض العام
- الصفحة التي يصل إليها المستخدم عند مسح كود QR
- تعرض كل بيانات الشهادة بتصميم رسمي يشبه موقع بلدي
- **لو الشهادة مقفولة**: يظهر رسالة "الشهادة مقفولة" 🔒
- يتضمن **هيدر بلدي الكامل** مع القوائم المنسدلة + **فوتر رسمي** مع ختم الحكومة الرقمية
- لايتطلب تسجيل دخول

### 📋 AllCertificates — جدول الشهادات
- جدول HTML لكل الشهادات (اسم، البرنامج التثقيفي، تاريخ الإصدار)
- زر نسخة احتياطية

## 🔌 نقاط الاتصال بالـ API

| الطريقة | المسار | الوظيفة |
|---------|--------|---------|
| `POST` | `/api/login` | تسجيل الدخول |
| `GET` | `/api/certificates` | جلب كل الشهادات |
| `GET` | `/api/certificates/:id` | جلب شهادة بالمعرف |
| `POST` | `/api/certificates` | إنشاء شهادة (multipart/form-data) |
| `PUT` | `/api/certificates/:id` | تحديث شهادة |
| `DELETE` | `/api/certificates/:id` | حذف شهادة |
| `GET` | `/api/certificates-next-number` | الرقم التسلسلي التالي |
| `GET` | `/api/certificates/license/:num` | البحث بالرخصة |
| `GET` | `/api/certificates-backup` | تحميل نسخة احتياطية |
| `POST` | `/api/certificates-restore` | استيراد نسخة احتياطية |

## 🔒 المصادقة (Authentication)

- يستخدم **JWT Token** يُخزن في `localStorage`
- الصفحات المحمية تتحقق من وجود Token
- عدم وجود Token ← إعادة توجيه لصفحة Login
- Token يُرسل في Header: `Authorization: Bearer <token>`
- صفحة `/view/:id` لاتتطلب مصادقة (عامة)

## 📝 ملاحظات مهمة

1. **كود QR**: كل شهادة تُنتج كود QR يُشير لـ `{domain}/view/{id}` — يمكن طباعته ومسحه للتحقق
2. **التقويم الهجري**: يُحسب تلقائياً باستخدام `islamic-umalqura` calendar
3. **رفع الصور**: يُرسل كـ `multipart/form-data` ← يُرفع إلى Cloudinary عبر الـ Backend
4. **قفل الشهادة**: يمكن قفل أي شهادة لمنع عرضها عند مسح الـ QR
5. **الترقيم التلقائي**: رقم الشهادة الصحية يُحسب تلقائياً من الـ Backend
6. **البحث بالرخصة**: إدخال رقم الرخصة يبحث عن بيانات سابقة ويملأها تلقائياً
7. **React Compiler**: مُفعّل عبر Babel Plugin لتحسين الأداء (قد يبطئ الـ dev/build)
